# Task Document Template

Write the descriptor's registered dated `*-tasks.md`:

```markdown
# <Goal> — Execution Tasks

## Status and authority

## Audit notes

## Dependency graph

### <stable task ID> — <achievable outcome>

- Goal:
- Target repository:
- Likely files/modules:
- Acceptance criteria:
- Local test and runtime QA notes:
- Documentation impact:
- Dependencies / blocks:
- Risks and non-goals:
- Completion/publication boundary:

## Sources consulted (paths)
```

Split cross-repository work into separate code-bearing tasks. Do not create an empty branch/PR for evidence-only operational work. Do not claim the tasker's `Audit notes` are independent audit sign-off.
