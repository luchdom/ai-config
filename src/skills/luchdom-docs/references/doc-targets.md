# Doc Targets

Use this ownership map when deciding what to update.

- `README.md`
  - high-level entry points
  - links to core docs
- `AGENTS.md`
  - repo workflow rules
  - autonomous mode policy
  - implementation guardrails
- `docs/HARNESS.md`
  - meaning of one-shot execution
  - stop conditions
  - outputs
- `docs/WORKFLOW.md`
  - planning/task/audit/implement sequence
  - mode behavior
- `docs/DECISIONS.md`
  - approval-required actions
  - Slack or human escalation policy
- `docs/QUALITY.md`
  - definition of done
  - validation commands
- `docs/LOCAL-DEVELOPMENT.md`
  - required tools
  - local bootstrap commands
- `docs/LINEAR.md`
  - intake gate for autonomous execution
- `docs/AI-TOOLING.md`
  - actual machine-state verification
  - missing tools and install references
